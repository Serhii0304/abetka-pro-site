# Знімки екрана для сайту

**Зараз галерея знімків на сайті прихована**, бо тут лежать графічні заготовки, а не
реальні кадри програми.

Щоб увімкнути галерею:

1. Замініть усі п'ять заготовок справжніми знімками з тими самими назвами.
2. У файлі `index.html` знайдіть рядок із `id="znimky"` і приберіть у ньому
   слово `hidden`. Над цим рядком є пояснювальний коментар.

Більше нічого змінювати не потрібно.

Загальні вимоги:

- формат — PNG;
- рекомендована ширина — 1600 px;
- пропорції — 16:9 або близькі до них;
- інтерфейс має бути чітким, без сторонніх вікон і персональних даних;
- використовуйте вигадані ПІБ;
- перед зніманням установіть масштаб Windows так, щоб текст легко читався.

## Потрібні файли

1. `01-golovne-vikno.png` — двопанельне головне вікно: ліворуч вхідний список,
   праворуч готовий результат; у кадрі мають бути помітні параметри сортування й
   нижні лічильники.
2. `02-import-word.png` — вікно структурованого імпорту таблиці Word із рядком
   заголовків, ролями колонок і попереднім переглядом.
3. `03-povtory.png` — головне або велике вікно результату з режимом
   «Позначити повтори» та кількома виділеними групами.
4. `04-poshuk.png` — живий пошук із введеним запитом, підсвіченими збігами та
   видимим лічильником.
5. `05-eksport.png` — вікно параметрів експорту у Word, Excel або PDF; бажано
   показати формат, орієнтацію чи колонки.

Після заміни відкрийте `index.html` і перевірте, що кожне зображення не розтягнуте,
не обрізане й відповідає підпису під ним.
