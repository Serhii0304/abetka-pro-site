# Сайт «Абетка Pro»

Це окремий публічний репозиторій сайту комерційної програми «Абетка Pro» —
portable-програми для впорядкування списків за сучасною українською абеткою.

Сайт створено на чистому HTML, CSS і JavaScript без зовнішніх залежностей, аналітики
та трекерів. Його можна відкрити локально через `index.html` або опублікувати на
GitHub Pages.

## Важливо

Вихідний код самої програми, генератор ліцензійних ключів, приватний ключ, видані
ліцензійні ключі та ZIP-дистрибутив у цьому репозиторії не публікуються.
Дистрибутив додається окремо до GitHub Release.
